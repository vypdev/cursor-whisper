# Anthropic Claude

Use Anthropic Claude models for prompt transformation.

## Configuration

```json
{
  "cursorWhisper.transformationProvider": "anthropic",
  "cursorWhisper.anthropicModel": "claude-3-5-sonnet-20241022"
}
```

## Setup

1. Get an API key from [Anthropic Console](https://console.anthropic.com/)
2. Run **Cursor Whisper: Configure Transformation Provider**
3. Select **Anthropic** and enter your API key

## Recommended Models

- `claude-3-5-sonnet-20241022` — Best quality (default)
- `claude-3-5-haiku-20241022` — Faster, lower cost
- `claude-3-opus-20240229` — Highest capability
